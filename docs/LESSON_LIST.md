# /list — черновик списка на занятие (read-only)

Команда доступна только `ADMIN_ID` и `KARINA_ID` в личном чате Акробота. Не создаёт посещений, платежей или записей в Google Sheets.

## Сценарий
1. Отправить `/list` и выбрать одну из настроенных групп.
2. Дождаться загрузки: ученики идут **в порядке строк вкладки группы**, а не вкладки `usernames`. Отдельно показаны возможные новые/несопоставленные участники опроса.
3. Кнопка: `☐/✅` (ручная отметка тренера), длинное тире, ответ опроса (`⭐` будет по абонементу / `❌` пропускает / `💵` разово / `❔` нет ответа), имя, ещё одно длинное тире и короткий статус абонемента. Ответ опроса — **подсказка**, он никого не отмечает автоматически. **Стандартные Telegram inline-кнопки центрируют свои подписи и не дают задать выравнивание по левому краю**: это клиентское ограничение, поэтому точные колонки имён здесь невозможны. Альтернатива — отдельный левосторонний текстовый список или Telegram Mini App, но текущая реализация сохраняет прямое нажатие на каждого ученика.
4. Нажатие переключает `☐` ↔ `✅`. В callback вшито **ожидаемое текущее состояние** (`0/1`); повтор того же callback игнорируется в течение 1 секунды только для `al:t:`; остальные команды сохраняют двухсекундную защиту. Намеренное снятие отметки использует новое ожидаемое состояние и работает сразу, без обязательного ожидания секунды. Устаревшее повторное нажатие не меняет состояние; edits сериализованы asyncio lock, при ошибке Telegram редактирования отметка откатывается. Для ограниченных абонементов показывается `(4/8)` / `(2/3)`; для безлимитных — `∞ (7/15)` в группах 6–9 и `∞ (5/10)` в младших и взрослых группах. Это **отображение Used**, а не изменение модели списания. Завершение по лимиту или дате помечается красным `❗` с сохранением счётчика; отсутствие будущих занятий и последнее занятие обрабатываются отдельно.
5. При наличии `не оплач` в колонке «Депозит» кнопка дополнительно показывает жёлтый `⚠️ не оплачено` (и сумму, если поместилась); используется общий `parse_unpaid_payment` из существующей системы. Если сумма не указана, показываем только `не оплачено`: доступные страницы не содержат надёжного единого справочника индивидуальных цен и частичных оплат, поэтому стоимость долга не угадываем. «Получить текст для копирования» отправляет выбранные имена в исходном порядке, добавляя после имени `(не оплачено)` либо `(не оплачено 1250)`. Других разделов и дополнительных полей нет.
6. «Обновить (сброс отметок)» перечитывает таблицы, теряя предыдущие ручные галочки.

## Источники и ограничения
- Список: `Группы 4-5`, `Группы 6-9`, `Взрослая группа`, данные загружаются из A2:AH, но используется **только первая основная таблица** — до повторного заголовка `Имя / Группа` (или `Имя Ребенка / Группа`). Вспомогательные списки ниже не являются посещаемостью и игнорируются. Ученики без абонемента внутри основной таблицы сохраняются. Дубликаты имён внутри неё убираются по нормализованному полному имени, сохраняется первое появление и его статус. Внутри вкладки строки фильтруются по `Группа` с учётом `group_config.py`.
- Привязка ответов: `User ID` / `username` из групповой вкладки, дополняемые `usernames` по имени ребёнка и технической группе. Несопоставленные участники показываются **по Telegram-имени**, без предположений, что это имя ребёнка.
- Опрос: идентификатор текущего занятия из `Репорты`, запасной вариант — строка создания из `Опросы`. Опрос за пределами ±1 дня не используется. Для каждого Telegram user ID берётся **последняя сохранённая строка с ответом** в `Опросы`.
- Удалённые голоса без повторного ответа по-прежнему не пишутся в `Опросы`; бот не может узнать об их отмене, и показывает последний сохранённый голос. Это только информационная подсказка.
- Статус: тип, лимит/Used/Unused, дата окончания, `WO Left until end`, `Difference` и `warning_7`; для неоплаты — `Депозит`. **День окончания ещё действителен**. Семантика `Difference` не должна использоваться как самостоятельное доказательство финансового или календарного списания.
- Доступ: только администраторы, проверка повторяется на callback. Сессия галочек хранится в `context.user_data` только в памяти; при рестарте нужна новая `/list`.
- Максимум 75 строк, по 12 кнопок на страницу, если данных больше — ошибка, а не неполный список.
- В качестве начальной версии Google Sheets читается одним `batchGet` для вкладки и трёх справочников. Если исторические `Опросы` станут очень большими, стоит добавить ограниченное чтение/кэширование, не меняя смысл «последний голос».

## Проверка
`pytest -q tests/test_lesson_list.py`
Полный набор: `pytest -q`.

Ручной smoke после развёртывания: авторизованный / неавторизованный пользователь, две разные группы, неполный/неизвестный username, два ответа на один опрос, пустая строка абонемента, повторные строки из нижних вспомогательных таблиц, дубль внутри основной таблицы, последний день/последнее занятие, отсутствие свежего опроса, копирование без дополнительных полей, галочка тренера и звезда ответа опроса перед именем, быстрые отметка/снятие отметки подряд в течение 2 секунд, старые дублированные callback, параллельные callback и rollback после сбоя редактирования, возрастные знаменатели безлимита (10/15), истечение срока с оставшимися занятиями и неоплата с суммой.
